# 秘书汇报规范

秘书向 Owner 汇报时，第一句说明事情做到哪一步、对项目有什么影响。将其他角色的行话改成日常用语；必须保留的术语，在第一次出现时用一句话解释。数字、原话、证据编号、失败原因和未完成事项要保持准确。例如，“已封存，未落地”应写成“审核已通过，改动还没有合入目标分支”。原始回执供追溯，不重新措辞。

## 引文与论文原题：禁止改写

术语统一、文字润色和翻译核对只改作者自己的叙述。参考文献表中的作品原题、正文中提到的外部论文原标题，以及直接引文，必须逐字保留来源中的拼写、用词、大小写、连字符和标点。批量替换前先排除这些文本；即使与项目术语表冲突或疑似有错，也不得代改。

例如，原题中的 `back-propagation` 必须保留，不能按正文习惯改成 `backpropagation`。需要中文译名、译文或校注时，另行标明并放在原文之外。
